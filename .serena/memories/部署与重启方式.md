# opencode-free-proxy：部署与重启

## 运行方式
- 以 **docker compose** 运行：容器名 `opencode-proxy`，镜像 `opencode-free-proxy-proxy`，`network_mode: host`，端口 6446。
- **没有** systemd 服务（`systemctl` 找不到）。
- 宿主机目录：`/home/sxkiss/opencode-free-proxy`

## 关键坑：改代码后不能只 restart
- `server.mjs` / `cluster.mjs` 等代码是用 Dockerfile `COPY . .` **打进镜像**的；compose 只挂载了 `./data` 和 `./api-keys.json`（运行时覆盖）。
- 因此修改 `server.mjs`（如 `MODELS` 列表）后，**`docker restart opencode-proxy` 无效**（旧镜像仍是旧代码）。
- 正确做法：`cd /home/sxkiss/opencode-free-proxy && docker compose up -d --build`（重建镜像+重建容器）。npm install 有 layer 缓存，主要成本是 `COPY . .`，通常十几秒完成。
- 仅改 `api-keys.json` / `data/` 才只需 restart。

## 验证生效
- 容器：`docker ps --filter name=opencode-proxy`
- 模型列表：`curl -s http://127.0.0.1:6446/v1/models`（本地直连，不走 HTTP_PROXY）
