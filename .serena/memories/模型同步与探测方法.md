# opencode-free-proxy：免费模型同步

## 关键事实
- 可用免费模型列表**硬编码**在 `server.mjs` 的 `MODELS` 数组（约第 59 行），`/v1/models` 只回吐静态列表，不自动发现新模型。改完需**重启进程**才生效（MODELS 为启动时常量）。
- 真正"免费模型"权威来源是 opencode.ai 的 Zen 免费层，实时清单接口：`GET https://opencode.ai/zen/v1/models`（需头 `Authorization: Bearer public` + `x-opencode-client: cli` + `x-opencode-project: global` + UA `opencode/1.15.0 ...`）。
- 本地出网走代理：`HTTP_PROXY=http://127.0.0.1:7890`（curl 需 `-x` 该代理）。
- 上游 GitHub 仓库通常只做 `yml` 配置提交，模型新增不体现在上游 commit，必须直接探测 Zen API。

## 探测方法（核查新模型）
1. `curl -x http://127.0.0.1:7890 … https://opencode.ai/zen/v1/models` 拿全量清单（含付费；免费模型多为 `-free` 后缀，但 `big-pickle` 无后缀也是免费）。
2. 对候选 `-free` 模型发最小 `chat/completions` 验证是否真能在免费层调用（新列出者也可能临时报 "Model is unavailable"/"Internal server error"，属上游故障，可先加入观察）。
